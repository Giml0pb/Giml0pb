## Selected work

### [STN-LFP medication-state decoding](https://github.com/Giml0pb/Giml0pb/blob/main/projects/stn-lfp.md)

Master's thesis: six-channel neural signals, spectral-temporal representations and Elastic Net classification. Leave-one-patient-out evaluation on 28 participants; nested model selection achieved **0.848 mean patient-level balanced accuracy**. The case study includes aggregate results, temporal controls, figures and their source tables.

### [Gait State Estimation Lab](https://github.com/Giml0pb/Gait_Project)

Fourier observation models, an extended Kalman filter and Hilbert baselines. Dataset-free demo, missing-sensor simulations and uncertainty diagnostics, with an installable CLI, tests, CI and Docker.
